**Задание 4. Проектирование облачной инфраструктуры с применением IaaS и Terraform**

---

## 1. Диаграмма автоматизации развёртывания

cм. файл Task4\diagram.png

**Компоненты, управляемые Terraform:**
- VPC, subnets, routing tables
- NAT Gateway
- Виртуальные машины (VM-Bastion, VM-App)
- Диски (boot + data) и snapshots
- Security groups / Firewall rules
- Object Storage bucket для состояния
- (опционально) Managed Kubernetes Cluster

**Компоненты, настраиваемые вручную (или через Ansible после Terraform):**
- Установка ПО на ВМ (Docker, Kafka, ClickHouse, PostgreSQL)
- Настройка приложений
- Создание Service Account и ключей доступа (выводятся через outputs)
- Настройка DNS-записей
- Настройка мониторинга (Prometheus/Grafana) – может быть автоматизирован через Helm

## 3. Тестирование и скриншот

Для тестирования выполните команды:

```bash
cd /Task4
terraform init
terraform plan
terraform apply -auto-approve
```

После успешного применения вы увидите вывод outputs:

```
Apply complete! Resources: 12 added, 0 changed, 0 destroyed.

Outputs:

bastion_public_ip = "51.250.x.x"
app_private_ip = "10.0.2.x"
app_data_disk_id = "disk-xxxxx"
vpc_id = "enpxxxxxx"
ssh_bastion_command = "ssh -i ~/.ssh/id_rsa ubuntu@51.250.x.x"
ssh_app_via_bastion_command = "ssh -J ubuntu@51.250.x.x ubuntu@10.0.2.x"
```

**Скриншот** выполнения `terraform apply` должен быть сохранён как `screenshot-apply.png` и приложен к пул-реквесту (в данном тексте скриншот не может быть вставлен, но команда предоставляет ожидаемый результат).
